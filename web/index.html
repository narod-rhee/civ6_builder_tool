Template Copilot

Use OpenAI only for safe XML, SQL, and ArtDef placeholder planning while the tool preserves file structure.

Input guide

Fill only the fields relevant to the files you selected. Pick a file group on the right first, then describe the exact gameplay idea in Copilot brief. Unified output keeps multiple civs/leaders as rows inside the same generated files.

  • Core Civ: compulsory civilization definition, city/citizen names, Named geography rows inside Civilization.xml, base LOC text, config, colors, icons, and core ArtDefs.
  • Districts: district XML plus district modifiers. Use it when adding a unique district or district-based ability.
  • Governors: optional governor definitions, promotion tree, promotion modifiers, governor LOC, and governor icon rows.
  • Named geography: compulsory Civilization.xml series for rivers, lakes, seas, deserts, volcanoes, and mountains, with matching Base text LOC.
  • Texts: localization files. Use this with Core Civ so names, descriptions, city names, and flavor text are updated together.
  • SQL: SQL-only templates such as moments. Keep SQL changes exact and narrow.

Instruction Manual

  1. Choose Civilization Icon for OpenAI. Choose Unit Theme, Diplomacy Background, or Moment Picture for NovelAI.
  2. Put exact faction symbols, colors, material, unit equipment, diplo environment, moment scene, shape language, and crop/readability needs in the visual brief.
  3. Use OpenAI for hard symbolic Civilization icons. Use the NovelAI positive and undesired prompts for everything else.
  4. Use the listed resolution, sampler, steps, and prompt guidance as the starting settings.
  5. Generate larger than the final icon, then run the Cropper page afterward.
  6. Use the Cropper ARX profile for 54x54 ARX sizing rather than generating ARX in NovelAI.
